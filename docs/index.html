Download for macOS →

What is it

Pumpkky は Ghostty の terminal engine の上に Zig core + Swift AppKit UI で乗せた、 macOS native の軽量コードエディタです。 Electron なし、アカウントなし、telemetry なし、Marketplace なし。 dotfiles 文化に立ち返って、あなたとファイルだけ。

8 つの設計哲学

  • 余分を削る (Ghostty の精神)
  • デフォルトで使える、設定は任意
  • 設定は必ずファイル (GUI 設定画面なし)
  • アカウント不要・telemetry なし
  • dotfile / Extension Point 文化 (Marketplace なし)
  • GPU 加速 native、Web エンジン非介在
  • upstream への敬意 (Ghostty 本家へ還元の道を残す)
  • OS ごとに Best な UI (core 共通、UI 各 OS native)

Build from source

git clone --recursive https://github.com/dngwkim0357-ai/Pumpkky
cd Pumpkky
./scripts/build-macos.sh
open dist/Pumpkky.app

Requirements: macOS 13+, Xcode (full), Zig 0.16+ (brew install zig).

Status

Pre-MVP (M3). Window launches, file tree works, Open Folder wired, LLM Chat panel scaffolded. Real terminal embed + multi-language grammar in v1.0.

// 06 Philosophy

Eight rules.

Borrowed from Ghostty's "carve away the excess" stance and adapted for an editor.

  1. Carve away the excess. If it doesn't earn its place, it doesn't ship.
  2. Defaults work. Config is optional. Open Pumpkky for the first time and start typing.
  3. Config is a file. There is no settings GUI. ~/.config/ghostty-editor/config, key = value.
  4. No account, no telemetry. Nothing leaves your machine without you explicitly running a CLI.
  5. Extensions are dotfiles, not marketplace. Drop shell / lua / zig scripts into hooks/, commands/, themes/.
  6. GPU-accelerated native. No web engine. Swift + AppKit on macOS, GTK4 on Linux, WinUI3 on Windows (v1.0+).
  7. Respect upstream. Ghostty is a submodule, not a fork. We give back when we can.
  8. Best UI per OS. Core in Zig is shared. UI is native to each platform.

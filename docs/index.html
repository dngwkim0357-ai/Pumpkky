// 01 — Open & Edit

フォルダを開く。
それだけで、編集が始まる。

「ようこそ」画面も、プロジェクトピッカーも、ウィザードもない。⌘O でフォルダを選び、左にファイルツリー、右にエディタペイン。それで作業が始まる。

エディタコアは Zig 製の Piece Table + tree-sitter。大きなファイルでも開閉が瞬時、編集中の構文ハイライトも即座に追随する。

セットアップ手順を読む →

// 02 — Chat

あなたの LLM を、
あなたのまま使う。

Pumpkky は起動時に $PATH をスキャンし、claude / codex / gemini / qwen を見つけて Chat パネルの dropdown に並べる。あなたが既に契約している CLI が、そのまま選択肢になる。

サブプロセスとして起動し、stdin にプロンプト、stdout からストリーミング応答。API キーは Pumpkky の中を通らない。CLI 側で管理する。

// 05 — Philosophy

8 つの設計原則。

Ghostty の "carve away the excess" 精神をエディタに移植した、Pumpkky の意思決定指針。

01

余計を削る

機能を加える前に、無くせないか問う。1 つでも残せたら勝ち。

02

デフォルトで動く

config を 1 行も書かなくても普通に使える。設定はパワーユーザーの楽しみ。

03

設定はファイル

GUI Preferences は作らない。~/.config/ghostty-editor/config 1 個だけ。

04

アカウント不要

サインインも telemetry も無い。インストールしたら、もう完結。

05

Marketplace なし

拡張は dotfile。hooks/ commands/ themes/ にスクリプトを置く。

06

Web エンジン非介在

GPU 加速 native。Electron に逃げない、これだけは譲らない。

07

Upstream への敬意

Ghostty は submodule、fork ではない。学んだ知見は本家に還元する道を残す。

08

OS ごとに Best な UI

Core は Zig 共通、UI は各 OS の native。macOS は AppKit、Linux は GTK4、Windows は WinUI3。

// 01What is it

Pumpkky is a code editor built on top of the Ghostty terminal engine. Zig handles the editor core (rope buffer, tree-sitter, FFI). Swift + AppKit handles the macOS UI. The result is a native app that opens instantly and stays out of your way.

It is not an IDE. It does not have a marketplace. It does not ask you to sign in. It does not phone home. If you want VSCode-style everything, this is the wrong tool.

// 02Features

file_tree

Open a folder, browse, click to open. Click. Open. That's the loop.

rope_buffer

Piece-table backed buffer + tree-sitter parse. Large files don't choke.

llm_chat

Side panel auto-detects claude / codex / gemini / qwen on your PATH.

url_preview

Open http://localhost:3000 in a tab. Drag to detach (v1.0).

config_file

Ghostty-compatible key = value at ~/.config/ghostty-editor/config. No GUI preferences.

extensions

dotfiles, not marketplace. Drop scripts into hooks/, commands/, themes/.

// 04Build from source

Don't trust the binary? Build it yourself. Submodules pull in Ghostty and tree-sitter so what you see is what you get.

# requires: macOS 13+, Xcode, brew install zig
git clone --recursive https://github.com/dngwkim0357-ai/Pumpkky
cd Pumpkky
./scripts/build-macos.sh
open dist/Pumpkky.app

// 05Philosophy

Eight rules. Borrowed wholesale from Ghostty's "carve away the excess" stance and adapted for an editor:

  1. Carve away the excess.
  2. Defaults work. Config is optional.
  3. Config is a file. There is no settings GUI.
  4. No account, no telemetry. Ever.
  5. Extensions are dotfiles. There is no marketplace.
  6. GPU-accelerated native. No web engine.
  7. Respect upstream. Ghostty is a submodule, not a fork.
  8. Best UI per OS. Core is shared, UI is native.

Read the long version in user-manual.md.

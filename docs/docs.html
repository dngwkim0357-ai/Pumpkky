Documentation

Everything you need to install, configure, extend, and uninstall Pumpkky. For the long form, see user-manual.md in the repo.

Install

  1. Click Pumpkky.dmg (stable URL — always the latest).
  2. Open the dmg. Drag Pumpkky.app to /Applications.
  3. First launch: right-click → Open (Gatekeeper bypass — see below).

First launch

Pumpkky ships unsigned (we don't pay Apple's $99/year Developer fee). macOS will warn the first time you open it. One-time fix:

  • Finder right-click → Open, then click "Open" in the dialog.
  • Or: System Settings → Privacy & Security → Open Anyway.

From the second launch, just double-click as normal.

Config file

Pumpkky reads ~/.config/ghostty-editor/config — same syntax as Ghostty (key = value, flat, comments with #). There is no settings GUI.

# ~/.config/ghostty-editor/config

# Ghostty-inherited keys
font-family = "JetBrains Mono"
font-size   = 13
theme       = "github-dark"

# Pumpkky-only keys (editor.* prefix)
editor.line-numbers   = true
editor.tab-size       = 4
editor.llm.default    = "claude"

LLM Chat

⌘⇧L opens the right-side Chat panel. Pumpkky scans your $PATH at launch and lists any of these CLIs it finds:

  • claude (Anthropic Claude Code)
  • codex (OpenAI Codex CLI)
  • gemini (Google Gemini CLI)
  • qwen (Alibaba Qwen CLI)

Each CLI runs as a subprocess; the prompt goes in on stdin, the response streams back from stdout. Pumpkky does not store or forward your API keys — that's the CLI's job.

To add a custom CLI: editor.llm.cli.<name> = "/full/path/to/cli" in config, restart.

Extensions

No marketplace. Just dotfiles. Drop scripts into:

~/.config/ghostty-editor/
├── hooks/          # on-file-save, on-llm-prompt, etc.
├── commands/       # callable via ⌘⇧P
└── themes/         # syntax color schemes

Scripts can be .sh, .ts, .lua, or compiled .dylib. The MVP ships the scan + registry plumbing; real hook execution is wired in v1.0.

Updating

MVP: manual.

  1. Come back to download.html.
  2. Download the new Pumpkky.dmg.
  3. Drop the new Pumpkky.app over the old one in /Applications.

Your config in ~/.config/ghostty-editor/ is preserved. v1.0 will integrate Sparkle for in-app one-click updates.

Uninstall

rm -rf /Applications/Pumpkky.app
rm -rf ~/.config/ghostty-editor       # config (optional)
rm -rf ~/.local/share/ghostty-editor  # caches/logs

No account, no server, no leftover analytics. Zero trace.

Troubleshooting

Pumpkky.app won't open at all (silent failure)

macOS Gatekeeper sometimes silently blocks unsigned dmgs from com.apple.quarantine. From a terminal:

xattr -cr /Applications/Pumpkky.app
codesign --force --deep --sign - /Applications/Pumpkky.app
open /Applications/Pumpkky.app

Want to see what actually fails on launch

/Applications/Pumpkky.app/Contents/MacOS/pumpkky

The executable will print to stderr instead of dying silently.

Build from source

You'll want this if you don't trust the dmg, or want to hack on the editor.

# requires: macOS 13+, Xcode (full), brew install zig
git clone --recursive https://github.com/dngwkim0357-ai/Pumpkky
cd Pumpkky
./scripts/build-macos.sh
open dist/Pumpkky.app

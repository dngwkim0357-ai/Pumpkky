Unsigned binary. Pumpkky は Apple Developer ID で codesign / notarize していません (= ハロウィン哲学 + コスト軽量化の意図的な選択)。初回起動時に Gatekeeper の警告が出ます。

First launch — Gatekeeper 解除

  1. dmg を DL → 開く → Pumpkky.app を /Applications にドラッグ
  2. 初回 double-click すると「開発元未確認」の警告
  3. 解除方法 A: Finder で右クリック → 「開く」 → ダイアログで「開く」
  4. 解除方法 B: System Settings → Privacy & Security → 下にスクロール → "Pumpkky was blocked..." 横の Open Anyway

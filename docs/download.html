macOS 13 (Ventura) or later, Apple Silicon (arm64).

⬇ Download Pumpkky.dmg Release notes / older versions →

Stable URL — always the latest release. Direct dmg, no redirect to a page.

Unsigned binary. Pumpkky は Apple Developer ID で codesign / notarize していません (= Ghostty 哲学 + コスト軽量化の意図的な選択)。初回起動時に Gatekeeper の警告が出ます。

Install (Ghostty 流の素直な手順)

  1. 上の Pumpkky.dmg ボタンで dmg を DL
  2. dmg を開く → Pumpkky.app を /Applications にドラッグ
  3. 初回 double-click で 「開発元未確認」警告が出る
  4. 解除方法 A: Finder で 右クリック → 開く → ダイアログで「開く」
  5. 解除方法 B: System Settings → Privacy & Security → 下にスクロール → Open Anyway
  6. 2 回目以降は普通に double-click で起動

Update (MVP: 手動)

現状の MVP は 手動 DL 方式です:

  1. このページに来て新しい Pumpkky.dmg を DL
  2. 古い /Applications/Pumpkky.app を削除 (or 上書き)
  3. 設定 (~/.config/ghostty-editor/) は保持されます

v1.0 で Sparkle 統合 (アプリ内通知 + 1-click 更新) 予定。 Ghostty も Sparkle を採用しています。

Uninstall

rm -rf /Applications/Pumpkky.app
rm -rf ~/.config/ghostty-editor    # 設定も消す場合
rm -rf ~/.local/share/ghostty-editor  # cache/logs

アカウントもサーバもないので、これで痕跡ゼロ。

Don't trust the binary?

Build from source ↓ (ソース完全公開、submodule で Ghostty 本体も透明)

git clone --recursive https://github.com/dngwkim0357-ai/Pumpkky
cd Pumpkky
./scripts/build-macos.sh
open dist/Pumpkky.app

Requirements: Xcode (full), Zig 0.16+ (brew install zig).

または、ソースから build

OS を問わず誰でも。binary を信用しない方も、開発に参加したい方も、こちらへ。 

# 必要: macOS 13+、Xcode (full)、brew install zig
git clone --recursive https://github.com/dngwkim0357-ai/Pumpkky
cd Pumpkky
./scripts/build-macos.sh
open dist/Pumpkky.app
Ghostty submodule と tree-sitter を含むので --recursive 必須。OS 別 build script は今後追加予定 (現在は build-macos.sh のみ)。

// macOS インストール手順

  1. 上の ↓ Pumpkky.dmg ボタンで dmg を DL
  2. dmg を開く → Pumpkky.app を /Applications にドラッグ
  3. 初回起動 — 右クリック → 開く → ダイアログで「開く」 (Gatekeeper bypass、未署名のため)
  4. 2 回目以降は普通に double-click
もし silent failure する場合 (macOS 15.2+ で報告あり):
xattr -cr /Applications/Pumpkky.app && open /Applications/Pumpkky.app で quarantine 属性を強制削除してから再起動。詳細は Docs のトラブルシュート →

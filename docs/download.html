Unsigned. We don't pay Apple's $99/year Developer fee — a deliberate Ghostty-philosophy choice. First launch needs a Gatekeeper bypass (right-click → Open), which is a 10-second one-time step.

Install

  1. Click ↓ Pumpkky.dmg above.
  2. Open the dmg. Drag Pumpkky.app to /Applications.
  3. First launch — right-click Pumpkky.app → Open → confirm in the dialog.
  4. From the second launch onwards, just double-click.

If it still won't open

macOS sometimes silently blocks unsigned dmgs. From a terminal:

xattr -cr /Applications/Pumpkky.app
codesign --force --deep --sign - /Applications/Pumpkky.app
open /Applications/Pumpkky.app

Update

MVP: manual. Come back here, download the new dmg, drop it over the old one. Your config in ~/.config/ghostty-editor/ survives.

v1.0 will integrate Sparkle for in-app "Check for Updates" (the same framework Ghostty uses).

Uninstall

rm -rf /Applications/Pumpkky.app
rm -rf ~/.config/ghostty-editor       # config
rm -rf ~/.local/share/ghostty-editor  # cache/logs

No account, no server, no leftover analytics. Zero trace.
